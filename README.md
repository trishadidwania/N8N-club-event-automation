# N8N-club-event-automation
Automated event management workflow using n8n integrating Google Sheets, Google Calendar, WhatsApp, Gmail and Instagram Graph API.
🚀 Built an Automated Campus Event & Blog Management System using n8n Automation

Designed and developed a smart workflow automation platform that centralizes, processes, and distributes campus event information in real time across multiple channels.

🔹 Key Highlights:
• Automated event collection from:

* Instagram Graph API
* Google Forms & Sheets
* College websites (RSS/Web Scraping)
* SMTP Email Triggers

• Intelligent data processing pipeline:

* Validation & normalization
* Duplicate handling
* Date/time parsing
* Event categorization

• Smart feed generation:

* Upcoming events filtering
* Category-wise organization
* Newspaper-style event feeds
* Real-time synchronization using Supabase

• Multi-channel automation:

* Google Calendar integration
* WhatsApp notifications
* Email reminders & weekly digests
* Instagram auto-posting using Facebook Graph API

• Built with:

* n8n
* Supabase
* Google APIs
* JavaScript Function Nodes
* REST APIs
* Web Scraping & RSS Feeds

🧠 Workflow Logic:
Trigger → Validate → Normalize → Store → Categorize → Generate Feed → Notify → Publish

This project focuses on solving fragmented campus communication by creating a scalable, event-driven automation ecosystem that keeps students updated automatically.
